time to first byte, San Francisco → London (one RTT 86.2 ms):
  HTTP/1.1 + TLS 1.2, new connection       4 RTT = 345 ms   (TCP 1 + TLS 2 + request 1)
  HTTP/1.1 or 2 + TLS 1.3, new connection  3 RTT = 258 ms   (TCP 1 + TLS 1 + request 1)
  HTTP/3 (QUIC), new connection            2 RTT = 172 ms   (QUIC+TLS together 1 + request 1)
  HTTP/3 (QUIC) 0-RTT resumption           1 RTT =  86 ms   (request rides with the handshake)
  any protocol, reused (warm) connection   1 RTT =  86 ms   (request 1)

with a CDN edge in San Francisco (MODEL: user ↔ edge RTT 5 ms; edge keeps a warm connection to London):
  TLS 1.3 to the edge, cache miss      2 × 5 (handshakes) + 5 + 86 (edge → London) = 101 ms
  TLS 1.3 to the edge, cache hit       3 × 5 = 15 ms
  direct to London, TLS 1.3            3 × 86 = 258 ms
