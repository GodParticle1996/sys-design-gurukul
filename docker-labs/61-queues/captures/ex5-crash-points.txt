A. ASLI ginti (lib/crash.js): ek message = ₹100 charge. Har step ke baad crash (ack se pehle) → message wapas
   aata hai (at-least-once) aur poora flow dobara chalta hai. Saath mein: do workers ko ek hi message ek saath mila —
   dono workers ke steps ke har mumkin kram mein kitni baar ₹200 kata?

tareeka                                          har crash point par charges   do workers: double charge
koi idempotency nahi                             ₹200                          2 of 2 kram
check → charge → record (video)                  ₹100, ₹200, ₹100              18 of 20 kram
ek DB transaction: id insert (UNIQUE) + charge   ₹100                          0 of 2 kram
provider ko Idempotency-Key = message id         ₹100                          0 of 2 kram

→ Video ka "check karo, kaam karo, phir id likho": charge ke baad aur id likhne se pehle crash = ₹200.
  Do workers ek saath check karein toh dono ko "nahi kiya" milta hai: 20 mein se 18 kram mein ₹200.
→ Ilaaj: id ka record aur kaam EK transaction mein (UNIQUE constraint), ya bahar ki API ko idempotency key do
  (Stripe: Idempotency-Key header). Asli processes + SQLite par same race: lab 49.
